# File-metadata-viewer
This is a metadata viewer written with Python, that has a GUI built with PyQt6. The application works for the most common files, videos, images audio and more.
Requirements:
PyQt6>=6.6.0
Pillow>=10.0.0
python-magic>=0.4.27
mutagen>=1.47.0
PyPDF2>=3.0.0
ffmpeg-python>=0.2.0
exifread>=3.0.0
